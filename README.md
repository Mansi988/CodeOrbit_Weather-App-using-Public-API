# 🌦️ Weather Application

This is a simple weather application built using HTML, CSS, and JavaScript. It allows users to search for a city and view its current weather information in a clean and easy-to-use interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Search weather by city
- Display current weather information
- Simple and responsive interface
- User-friendly design

## 🎯 Purpose

This project was created to practice web development skills and learn how JavaScript can be used to work with weather data and create interactive applications.
